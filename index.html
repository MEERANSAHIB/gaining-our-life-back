Firebase Security Rules & Cloud Setup

Step-by-step instructions to allow cloud syncing across devices.

Step 1: Enable Anonymous & Google Auth

Go to Firebase Console > Build > Authentication > Sign-in method > Enable Anonymous and Google.

Step 2: Publish Firestore Rules

In Firebase Console > Build > Firestore Database > Rules, paste these exact rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
